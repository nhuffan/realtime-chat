# Rapid Chat

**Rapid Chat** is a real-time iOS messaging application built with SwiftUI and Firebase. It supports instant conversations and multimedia sharing through a simple, native iOS interface.

## Features

- Real-time text messaging
- Voice, image, and video messages
- Multimedia sharing and emoji support
- Online user status updates
- Firebase Authentication

## Tech Stack

| Area | Technologies |
| --- | --- |
| Language & UI | Swift, SwiftUI, UIKit |
| Backend | Firebase Firestore, Authentication, Storage |
| Media | AVKit, AVFoundation |
| Images | Kingfisher |
| Reactive Updates | Combine |
| Development | Xcode |

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/nhuffan/realtime-chat.git
   ```
2. Open `ChatAppSwiftUI/ChatAppSwiftUI.xcodeproj` in Xcode.
3. Configure the required Firebase project settings.
4. Build and run the app on an iOS simulator or device.
